# Cubase setup (1.0)

Keyboard → instrument track MIDI Inserts: Piano Auto Sustain Cubase → piano instrument.

Select the physical keyboard input and enable monitoring. To record generated CC64, put the plugin ABOVE Cubase's dotted MIDI insert recording divider (drag the divider below the plugin). Save the project. No Recorder, virtual port or machine-specific track preset is required.

See ../../docs/QUICKSTART-en.md. The user has confirmed live sound, recording sustain and captured CC64 with this processing logic.
