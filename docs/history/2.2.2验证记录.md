# 2.2.2 验证记录

日期：2026-10-12。范围：Windows x64 Cubase MIDI 插入 DLL。

## 确认的问题与修复

- 2.2.1 非实时事件直接返回，未送入延音引擎。新回归测试先失败，恢复处理后通过。
- 回放音符按 Cubase 的起点和长度分别观察按下、松开；原事件原样且只转发一次，不重建音符。
- 实时弹奏使用单调时钟，回放使用 PPQ 与宿主速度，两条时间线独立。
- startAction 不再清空已按住的实时和弦或宿主预读事件；定位、循环跳转清理回放状态并保留实时按键。
- 自动模式统一接管 CC64；关闭自动模式恢复原事件直通。

## 已执行的自动验证

MSVC Release 构建成功；CTest 14/14 通过。包括 DLL 工厂/版本/接口、界面创建、踏板引擎、和弦保护、时间线与原生宿主模拟。历史 Recorder/core 测试也保留通过，但本次不交付 Recorder。

新增宿主模拟覆盖：回放下踏与尾音释放的精确 PPQ、原音符时长与力度不变、录音开始保留踏板、预读事件不被清空、循环跳转、长音符、定位时实时按键保持、实时与回放不同通道独立释放。
