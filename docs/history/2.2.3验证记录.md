# Piano Auto Sustain 2.2.3 — 实机日志驱动的时间修复

依据：tests/fixtures/cubase15-timing-trace.log，2026-10-12 用户 Cubase 15 现场记录。

观察到 ppq=480，context.tempo=70（直接 BPM），原实现除以 1000 后又被引擎限为 1 BPM；日志中的实际回调推进速度约为 560 tick/s，与 70 BPM * 480 / 60 相符。

同一实时输入在播放中带绝对时间 5023355，而 immediate playAction 使用相对时间 1663。原实现混用接收事件与回调的时间戳发送 CC64。现在所有实时 CC64 以最近 immediate 回调时间为锚点，按单调时间和当前 BPM 外推；原始音符不修改。回放时间线支持直接 BPM 与旧 SDK 的 BPM * 1000 表示。

回归测试分别先复现速度单位错误、CC64 时间域错误，修复后通过。仍保留自动日志，改为允许共享读取，无需关闭 Cubase 即可查看。

实机状态：2.2.2 已确认未通过；2.2.3 的真实音源效果待验证。现场记录只有实时音符，没有非实时片段回放音符；不可由该记录宣称片段回放已通过。

本版继续只交付 Windows x64 Cubase MIDI 插入，不需要 Recorder。音符录入片段，回放由插件重算 CC64；不自动把 CC64 写入片段。
